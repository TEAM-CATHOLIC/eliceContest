# 일반 앱의 완료 메일 근거

계정 인벤토리에서 탈퇴 안내를 시작한 뒤 Gmail/파일을 다시 가져오면, 이번 안내 이후 같은 서비스에서 받은 명시적 완료 표현을 상세 화면에 표시한다. 기존 6종 메일 분류 계약이나 모델 가중치는 바꾸지 않는다.

- `사용자 완료 확인`은 사용자가 '탈퇴를 끝냈어요'로 표시한 상태다.
- `완료 표현 메일 발견`은 별도 근거다. 근거 메일 보기 버튼으로 본문 앞부분을 확인한다.
- 메일만으로 DONE 상태를 만들거나 재알림·로그인 세션을 지우지 않는다. 메일이 없으면 실패로 판단하지 않는다.
- 안내 시각과 이미 가져온 메일 ID를 로컬 DB에 저장한다. 재시도하면 새 기준을 잡고 이전 완료 상태를 초기화한다. 기존 세션의 14일 보관 시작 시각은 연장하지 않는다.
- 과거 메일·기존 ID·다른 서비스·전달/인용문·요청·삭제 예정·구독 해지는 완료 근거로 사용하지 않는다. 현재 탐지기는 명시적인 한국어 표현을 지원한다.
- 실시간 Gmail 감시는 아니다. 사용자가 메일을 다시 가져와야 한다. 추적 기준이 없는 이전 버전 진행 기록에는 추정 결과를 만들지 않는다.
- 근거 본문은 기존 암호화 저장 정책을 따른다. 재시작하면 저장된 미리보기에서 근거를 다시 찾는다. 미리보기 밖의 표현, 키 분실, 다른 메일함으로 교체한 경우 근거가 표시되지 않을 수 있다.
- 서비스 도메인별 근거이며 동일 서비스의 여러 수신 계정 구분이나 발신자 인증 검증은 하지 않는다. '실제 계정 삭제 확인'이라고 표현하지 않는다.

실제 수신된 탈퇴 완료 메일은 아직 검증하지 못했다. 현재 통합 검증에는 합성 메일을 사용한다.
