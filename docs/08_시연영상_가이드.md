# 08. 시연 영상 촬영 가이드 (2분 40초)

> 제출물 ② PoC: **시연 영상** + 웹 소개 페이지 + 실행 파일(Release). 영상은 "설치하지 않아도 작동 방식이 보이게"가 목표다.
> 한 줄 메시지: **"잊힌 계정을 메일에서 찾아, 탈퇴 화면 바로 앞까지 데려다준다. 비밀번호와 최종 버튼은 사람이."**

## 1. 찍기 전 준비

| 항목 | 할 일 |
|---|---|
| 계정 | **시연용 Gmail·서비스 계정**을 쓴다. 본인 메일 주소·이름이 화면에 나오면 편집에서 모자이크 |
| 이름 노출 | 로그인한 사이트 헤더의 사용자 이름(예: 인프런 우측 상단)이 찍히지 않게 하거나 가린다 |
| 데이터 | 실제 분석 장면이 어려우면 `uv run python app/scripts/design_preview.py`(가짜 데이터)로 찍는다. 자막에 "시연용 데이터" 표기 |
| 화면 | 1920×1080, 앱 창 최대화, 알림 끄기(방해 금지), 바탕화면·북마크 정리 |
| 녹화 | OBS(무료) 또는 Windows `Win+Alt+R` / macOS `Cmd+Shift+5`. 앱 창과 Chrome 창을 나란히 두면 컷 편집이 줄어든다 |
| 성공 장면 | **Dropbox(플레이북)** 와 **플레이북 없는 사이트 1곳(AI 안내)** 을 미리 리허설해서 끝까지 가는 걸 확인 |
| 기다림 | 로그인·AI 응답 대기는 편집에서 2~4배속 + 자막 "실제 시간 1분 20초"로 정직하게 표기 |
| 음성 | 내레이션 없이 **자막 + 잔잔한 BGM**이 무난하다. 넣는다면 아래 자막을 그대로 읽어도 된다 |

| 13 | 2:33–2:40 | 로고 + 한 줄 + 링크 | — | **"잊힌 계정, 메일 속 흔적으로 찾아 안전하게 지웁니다"** / 팀명 · 웹 소개 주소 |

**꼭 보여야 하는 장면 4개** (시간이 모자라면 나머지를 줄인다): ⑥ 근거 문장, ⑨ 사람이 로그인, ⑩ 최종 버튼 앞에서 멈춤, ⑪ 처음 보는 사이트.

## 3. 편집 팁
- 자막은 화면 아래 1/5, 한 번에 **한 줄 20자 안팎**, 2.5초 이상 유지
- 클릭 위치에 원형 강조(OBS 플러그인 또는 편집 툴의 커서 하이라이트)
- 배속 구간은 우측 상단에 `▶▶ 4×` 표기
- 숫자가 있으면 강조: 재현율 97~99%(정답 계정 88개 기준, [모델카드](05_모델카드_학습근거.md)) — 컷 6 자막에 붙여도 된다
- 내보내기: 1080p, MP4(H.264), 100MB 안팎 → Google Drive 링크 + 웹 페이지에 삽입

## 4. 찍고 나서 확인
- [ ] 실제 메일 주소·이름·사용자명이 한 프레임도 안 나온다
- [ ] 비밀번호 입력 장면이 가려져 있다
- [ ] 최종 탈퇴 버튼을 앱이 누르는 장면이 없다 (사용자가 누르거나 누르지 않고 끝)
- [ ] 배속 구간 표기가 있다
- [ ] 2분 40초 안쪽이다
